== September 2026 iteration: SKaiNET 0.53 two-model pipeline

Goal: a working JVM CLI on the released SKaiNET / SKaiNET-transformers
0.53.0, with Qwen3-0.6B calling `get_recent_commits` (function calling) and
Llama-3.2-3B-Instruct (Q4_K_M) writing the summary, expressed as an extendable
SKaiNET data pipeline (`standupFlow {}` over `sk.ainet.data.source.DataPipeline`).
Legacy single-model paths (embedded 1B JAR resource, `--tool-calling`) are
replaced. See xref:design.adoc[DES-08..DES-10] and xref:requirements.adoc[REQ-50..REQ-55].
